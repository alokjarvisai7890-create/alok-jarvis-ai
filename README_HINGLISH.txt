ALOK AI - ANDROID STARTER ZIP
=============================

Is ZIP mein kya hai?
- ALOK ka mobile-friendly app prototype
- Friendly male-style avatar illustration
- Hinglish chat ka demo
- Avatar par double-tap se Secret Menu
- Voice settings: phone ke available text-to-speech voices, pitch aur speed
- Character theme changer
- PWA support (website ko home screen par app jaisa install kar sakte ho)

IMPORTANT LIMITATIONS
---------------------
1. Ye starter prototype hai, abhi full ChatGPT jaisi AI nahi hai. Replies demo rules se aate hain.
2. Voice changer abhi phone ki text-to-speech voice/pitch/speed adjust karta hai. Real-time mic voice conversion nahi.
3. Character changer abhi avatar ka color/theme badalta hai. Full 3D character models baad mein add honge.
4. Mic input browser support aur permission par depend karta hai.
5. PWA install ke liye files ko HTTPS website par host karna hota hai. Sirf ZIP ko unzip karke index.html kholne se "Install app" har phone/browser mein nahi dikhega.

ANDROID PAR SABSE AASAN TAREEQA (MOBILE SE)
------------------------------------------
OPTION A: GitHub Pages (free hosting)
1. ZIP ko phone mein download karke extract karo.
2. Chrome mein github.com kholo aur free account banao/login karo.
3. New repository banao. Naam: alok-ai
4. Repository ko Public rakho.
5. "Add file" > "Upload files" se is folder ke andar ki saari files upload karo:
   index.html, style.css, app.js, manifest.json, sw.js
   README_HINGLISH.txt optional hai.
6. Commit changes dabao.
7. Repository Settings > Pages kholo.
8. "Deploy from a branch" select karo; Branch: main; Folder: /(root); Save.
9. GitHub Pages jo HTTPS link de, use Chrome mein kholo.
10. Chrome ke 3-dot menu > "Add to Home screen" ya "Install app" dabao.
11. ALOK icon home screen par aa jayega.

OPTION B: Local preview
1. Play Store se Acode ya koi HTML editor install karo.
2. ZIP extract karke folder Acode mein open karo.
3. index.html preview/run karo.
   Note: local preview mein PWA install/offline features kaam na bhi karein.
